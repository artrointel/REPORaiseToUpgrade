# 수동 테스트 계획

## 싱글플레이

1. 상점 진입 전 능력치를 기록한다.
2. 업그레이드 아이템을 1초 잡았다 놓고 다시 잡는다.
3. 두 번째 grab을 2초 유지해야만 능력치가 정확히 `+1` 되는지 확인한다.
4. 아이템이 사라지지 않고 구매 수량과 잔액도 변하지 않는지 확인한다.
5. 같은 상점의 다른 아이템을 2초 잡아도 추가 보상이 없는지 확인한다.
6. 다음 스테이지 후 상점에서 다시 한 번 선택할 수 있는지 확인한다.

## 멀티플레이 호환성

테스트 인원은 최소 두 명이며, 방장만 RepoHell을 설치한다.

1. 순정 참가자가 아이템을 2초 잡아 자신의 능력치만 `+1` 되는지 확인한다.
2. 방장과 참가자가 각각 다른 아이템을 선택할 수 있는지 확인한다.
3. 두 명이 같은 아이템을 동시에 잡아도 각자 한 번씩 적용되는지 확인한다.
4. 참가자가 2초 직전에 손을 놓으면 보상을 받지 않는지 확인한다.
5. 이미 선택한 참가자의 재시도와 동시 grab으로 중복 보상이 생기지 않는지 확인한다.
6. 참가자가 나갔다 다시 들어오는 상황에서 오류나 다른 플레이어 오지급이 없는지 확인한다.

## 회귀 확인

- 아이템 구매와 순정 업그레이드 사용이 기존대로 동작한다.
- 상점 밖에서 업그레이드 아이템을 잡아도 무료 보상이 발생하지 않는다.
- 방장이 아닌 모드 사용자가 순정 방에 참가해도 기능을 임의 실행하지 않는다.
- BepInEx 로그에 예외가 반복 기록되지 않는다.
