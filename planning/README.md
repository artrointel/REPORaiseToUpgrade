# RepoHell 기능 명세

## 한 문장 설명

상점에서 원하는 업그레이드 아이템을 2초 동안 잡아, 플레이어마다 상점당 한 번 무료 `+1`을 선택한다.

## 확정 규칙

1. 기능은 상점에서만 활성화된다.
2. 플레이어별 제한은 상점당 최초 1회다.
3. 같은 업그레이드 아이템을 연속으로 2초 동안 잡아야 한다.
4. 2초 전에 손을 놓으면 진행 시간이 즉시 초기화된다.
5. 성공하면 잡은 아이템 종류에 대응하는 해당 플레이어의 능력치만 `+1` 된다.
6. 성공 여부와 무관하게 아이템은 사라지거나 구매 처리되지 않는다.
7. 한 아이템을 여러 플레이어가 함께 잡아도 각자 독립적으로 시간을 계산한다.
8. 이미 선택을 마친 플레이어가 다른 아이템을 잡아도 추가 보상은 없다.

## 멀티플레이 원칙

- 방장이 grab 상태, 2초 유지, 상점당 1회 제한을 판정한다.
- 보상은 순정 게임에 포함된 업그레이드 RPC로 전파한다.
- 따라서 방장만 RepoHell을 설치하면 되고 참가자는 별도 설치가 필요 없다.
- 모드를 설치한 참가자가 순정 방에 들어간 경우에는 기능이 실행되지 않는다.

## 구현 범위

지원하는 순정 업그레이드 아이템:

- 체력, 스태미나, 이동 속도
- 추가 점프
- 잡기 거리, 잡기 힘, 던지기 힘
- 구르기 발사, 오르기, 날개, 웅크리기 회복
- 지도 플레이어 수
- 데스 헤드 배터리

이번 버전에서는 진행 UI, 효과음, 설정 메뉴, 신규 아이템을 추가하지 않는다. 순정 참가자에게 추가 자산을 내려받게 하지 않기 위한 의도적인 범위 제한이다.

## 완료 조건

- 싱글플레이와 방장 환경에서 2초 연속 grab 후 정확히 한 번 `+1` 된다.
- 손을 놓았다 다시 잡으면 2초를 처음부터 세어야 한다.
- 업그레이드 이후 아이템이 그대로 남는다.
- 같은 상점에서 두 번째 아이템으로 추가 업그레이드를 받을 수 없다.
- 다음 상점에서는 다시 한 번 선택할 수 있다.
- 순정 참가자가 자신의 능력치 증가를 실제 플레이에서 확인할 수 있다.
