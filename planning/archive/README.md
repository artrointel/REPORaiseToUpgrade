## 최우선 제품 원칙

> 방장만 RepoHell을 설치해도, 모드를 설치하지 않은 순정 R.E.P.O. 참여자가 추가 설치 없이 해당 기능을 정상적으로 경험할 수 있어야 한다.

이 원칙은 편의 기능이 아니라 출시 조건이다. 기능이 재미있더라도 이 조건을 만족하지 못하면 기본 RepoHell 모드에는 포함하지 않는다.

| 항목 | 상태 |

## 기획 진행 순서

1. `feature-proposals.md` 형식으로 기능을 제안한다.
2. 호스트 권한만으로 구현 가능한지 확인한다.
3. 순정 클라이언트가 이해할 수 있는 기존 게임 상태만 사용하는지 확인한다.
4. 실패·중도 참가·레벨 전환 상황의 복구 방식을 정의한다.
5. 최소 프로토타입을 만든다.
6. `multiplayer-test-plan.md`의 필수 시나리오를 모두 통과시킨다.
