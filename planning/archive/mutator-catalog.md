# 스테이지 변칙 후보 (이전 기획)

아래 아이디어는 기획 후보이며 구현 가능성이 확정된 기능이 아니다. 각 후보는 코드 조사와 순정 클라이언트 실험을 통과해야 한다.

## MVP 권장 후보

첫 버전은 서로 다른 변화 축을 대표하고, 순정 참여자가 결과를 직접 관찰할 수 있는 세 가지로 제한한다.

### M-001: 보물 소굴

> 가치품이 넓게 흩어지는 대신 일부 위험한 구역에 집중된다.

- 변화 축: 위치
- 플레이 변화: 넓고 안전하게 훑을지, 위험한 한 구역을 함께 공략할지 선택한다.
- 위험: 가치품 밀집 구역 주변에 적 또는 위험 요소도 함께 집중된다.
- 보상: 성공하면 짧은 동선으로 큰 수익을 얻는다.
- 이해 방식: 빈 방이 이어진 뒤 가치품과 적이 몰린 방을 발견하므로 차이가 즉시 보인다.
- 호스트 구현 가설: 레벨 생성 시 기존 가치품 스폰 결과를 호스트가 선택한 순정 Level Point 주변으로 편향한다.
- 주요 실험: 생성 완료 전에 배치를 바꿀 수 있는지, 기존 Photon 스폰이 순정 참여자에게 동일하게 보이는지 확인한다.

### M-002: 현상금

> 특정 적을 쓰러뜨리면 그 자리에서 순정 가치품이 보상으로 등장한다.

- 변화 축: 관계
- 플레이 변화: 평소 피하던 적과 싸울 이유가 생긴다.
- 위험: 전투 중 가치품이 손상되거나 팀원이 위험해질 수 있다.
- 보상: 적의 위협도에 맞는 가치품을 얻는다.
- 이해 방식: 적의 죽음 직후 같은 위치에 가치품이 등장하는 인과관계를 반복해서 보여준다.
- 호스트 구현 가설: 호스트가 적 사망을 확정한 뒤 기존 가치품 스폰 경로를 호출한다.
- 주요 실험: 적 사망 권한, 중복 사망 콜백, 생성된 가치품의 순정 동기화를 확인한다.

### M-003: 늦은 출근

> 초반은 평소보다 조용하지만 시간이 지날수록 기존 적들이 단계적으로 합류한다.

- 변화 축: 시간
- 플레이 변화: 초반에 빠르게 흩어져 수집하고, 상황이 악화되기 전에 합류하거나 철수한다.
- 위험: 욕심을 부릴수록 귀환 동선에 적이 늘어난다.
- 보상: 초반 탐색 창과 추가 가치품 또는 낮은 초기 위협을 제공한다.
- 이해 방식: 안전한 초반과 눈에 띄는 적 합류가 대비된다. 적 출현에는 기존 소리와 움직임을 사용한다.
- 호스트 구현 가설: 초기 적 예산 일부를 보류하고 호스트 타이머가 기존 적 스폰 경로로 나누어 투입한다.
- 주요 실험: 런타임 적 스폰의 네트워크 안전성, 스폰 위치의 공정성, 중도 참가 상태를 확인한다.

## 후속 후보

### M-004: 생태 편향

한 스테이지에서 특정 적 계열이 평소보다 자주 등장한다. 수치만 늘리기보다 그 적에 맞는 동선과 대응 도구의 가치가 바뀌게 한다.

### M-005: 이삿날

대형 가치품의 비중과 수익이 높아져 혼자 흩어지는 것보다 운반 협동이 중요해진다. 무게·물리를 직접 변경하지 않고 기존 대형 가치품의 구성만 바꾼다.

### M-006: 잔챙이 천국

작은 가치품이 대량으로 등장해 카트 운용, 왕복 횟수와 욕심 관리가 달라진다. 오브젝트 수 증가에 따른 성능 한도를 반드시 측정한다.

### M-007: 포식자와 먹잇감

서로 다른 기존 적의 조합과 배치를 의도적으로 구성해 플레이어가 혼란을 이용할 기회를 만든다. 실제 적 상호작용이 순정에서도 동일하게 동기화되는 조합만 사용한다.

### M-008: 마지막 한탕

기본 목표를 달성한 뒤 선택적으로 노릴 수 있는 위험한 가치품 밀집 구역을 남긴다. 추가 목표 UI 없이도 “이미 탈출 가능하지만 더 가져갈 수 있다”는 순정 의사결정을 강화한다.

## 보류할 아이디어

다음 유형은 C-001 위반 가능성이 커서 초기 범위에서 보류한다.

- 가치품의 무게나 깨짐 수치를 동적으로 바꾸는 변칙
- 플레이어 체력, 스태미나, 인벤토리 규칙 변경
- 화면 효과, HUD 경고 또는 전용 설명이 필수인 변칙
- 새로운 적, 아이템, 함정 또는 맵 에셋
- 순정 참여자가 받을 수 없는 커스텀 RPC 기반 사건

## 후보 평가 점수

각 변칙을 1~5점으로 평가한다. `순정 호환성` 또는 `이해 용이성`이 4점 미만이면 MVP에 포함하지 않는다.

| 평가 항목 | 질문 |
| --- | --- |
| 순정 호환성 | 방장 패치와 기존 동기화만으로 완성되는가? |
| 이해 용이성 | 설명 없이 첫 플레이에서 관계를 파악할 수 있는가? |
| 선택 변화 | 평소와 다른 의미 있는 결정을 만드는가? |
| 위험/보상 | 위험을 감수할 납득 가능한 보상이 있는가? |
| 반복 가치 | 강도와 배치가 달라도 재미가 유지되는가? |
| 구현 비용 | 작은 프로토타입으로 핵심을 검증할 수 있는가? |
| 충돌 안전성 | 순정 난이도 및 다른 변칙과 함께 안전한가? |
